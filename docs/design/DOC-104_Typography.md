# 1. Purpose

Typography is the primary tool for creating hierarchy, rhythm, elegance, and trust across the ARCHIVE platform.

Typography has higher priority than color, borders, icons, shadows, or decorative elements.

Whenever hierarchy can be created using typography instead of visual decoration, typography must always be preferred.

---

# 2. Typography Philosophy

ARCHIVE communicates through typography.

The interface should feel editorial rather than technical.

Large headings.

Comfortable reading.

Generous spacing.

Calm rhythm.

Perfect alignment.

Typography must create confidence before users consciously notice it.

# 7. Paragraph Width

Maximum comfortable reading width

70 characters

Long-form content should never span the entire screen width.

Readable typography is more important than using available space.

---

# 8. Heading Rules

Every page should have exactly one visual H1.

Avoid multiple dominant headings.

Headings should create rhythm rather than noise.

Never stack several large headings close together.

---

# 9. Body Text

Body text should feel effortless to read.

Avoid:

dense paragraphs

small line height

overly narrow spacing

long uninterrupted blocks

Comfortable reading is mandatory.

---

# 10. Prices

Prices are one of the most important typography elements.

Prices should always receive stronger visual emphasis than metadata.

Recommended:

24–32 px

Weight

600

Currency should appear slightly less prominent than the numeric value.

---

# 11. Product Titles

Product titles should dominate product metadata.

Maximum:

2 lines

Overflow:

ellipsis

Avoid extremely long product names.

---

These should all use secondary typography.

Metadata should support content, never dominate it.

# 13. Buttons

Buttons should never rely on size for importance.

Typography creates button hierarchy.

Button labels should remain concise.

Avoid:

---

# 17. Uppercase Usage

Uppercase should be used sparingly.

Allowed:

Navigation

Section labels

Overlines

Categories

Filters

Avoid uppercase in body text.

Avoid uppercase in long headings.

---

# 18. Text Alignment

Default

Left aligned

Center alignment should only be used when composition explicitly requires it.

Right alignment should primarily be used for numbers.

Avoid justified text.

---

---

# 20. Vertical Rhythm

Spacing between typography elements should follow a consistent rhythm.

Never visually compress headings against paragraphs.

Headings require generous whitespace above and below.

Typography should breathe.

---

# 21. Line Length

Ideal

50–70 characters

Maximum

80 characters

Long text should never stretch edge-to-edge.

---

# 22. AI Implementation Rules

AI tools must never invent new typography styles.

Only styles defined in this document may be used.

If an exact match does not exist, select the closest larger predefined style rather than creating a custom one.

Typography consistency always takes priority over visual experimentation.

---

# 23. Definition of Success

Users should perceive the interface as calm, effortless, and refined.

Typography should quietly guide attention without demanding it.

The interface should resemble a premium editorial publication rather than a conventional web application.

If users notice the typography itself, it is likely too expressive.

Excellent typography is almost invisible, yet it defines the entire experience.
